# 🚀 Quick Start Guide - RFP Agentic Platform

## 30-Second Setup

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. (Optional) Set API key for LLM enhancement
export OPENAI_API_KEY="your-key-here"

# 3. Run the pipeline
python main.py path/to/your/rfp.pdf
```

## ✅ That's it! 

The platform will generate:
- ✅ Compliance matrix
- ✅ Architecture mappings (Azure/AWS/GCP)
- ✅ draw.io diagrams
- ✅ Cost estimates
- ✅ Executive proposal pack
